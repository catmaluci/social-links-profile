This is my solution to the Social links profile challenge on Frontend Mentor.

## Overview ✨

### The Challenge

Users should be able to:

- View the optimal layout for the site depending on their device's screen size

- See hover and focus states for all interactive elements on the page

## My Process 🛠️

### Built with
- **Semantic HTML5 markup** - Used meaningful tags for better accessibility and structure
- **CSS Custom Properties** - For colors and fonts, making the design easy to maintain.
- **Flexbox** - For layout and centering content.
- **Mobile-first workflow** - Designed for mobile first, then adapted for desktop.

### What I learned 💡

This project was excellent practice for creating a clean, accessible profile card with interactive elements. I focused on:

- **Responsive Design:** Used media queries to ensure the layout looks great on all devices

- **CSS Variables:** Implemented custom properties to manage the color scheme efficiently

- **Interactive States:** Created smooth hover and focus effects for all social links

- **Accessibility:** Ensured proper focus indicators and semantic HTML for screen readers
